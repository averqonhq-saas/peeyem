# Peeyem Traders

Industrial Conveyor & Rubber Solutions engineered for high-tonnage mining, aggregate, and manufacturing operations.

## Features

- **Modern 3D Parallax Experience**: Multi-layer GPU-accelerated depth effects with device orientation and scroll parallax.
- **Product Showcase**: Chevron incline cleated belting, multi-ply flat carcass belting, and abrasion-resistant industrial rubber sheets.
- **Interactive RFQ System**: Instant quote request modal and WhatsApp integration.
- **Full Administrative Control Portal**: Product management, testimonials, promotional videos, customer enquiry tracker, and visual gallery manager.
- **Cloud Integrations**: Firebase Firestore and Cloudinary CDN storage.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database / Auth**: Firebase Firestore & Firebase Auth
- **Media**: Cloudinary CDN

## Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/averqonhq-saas/peeyem.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) with your browser.
